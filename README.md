# Locos

A local technician marketplace where customers can discover and request nearby technicians such as plumbers, carpenters, electricians, mechanics, and more.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Django
- Django REST Framework

### Database
- PostgreSQL
- PostGIS (for location-based search)

## Core Features

### Customers
- Register and login
- Find nearby technicians
- Filter by category, distance, and rating
- View technician profiles
- Request technicians for jobs
- Track job status
- Rate and review technicians

### Technicians
- Register and login
- Create technician profile
- Select service category
- Receive job requests
- Accept/reject jobs
- Update job status
- Receive customer ratings
